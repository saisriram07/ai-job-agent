# Smart Attendance Monitoring System - Website

A professional one-page website for the Smart Attendance Monitoring System, designed to reduce absenteeism in Andhra Pradesh colleges using a silent, automated tracking method.

## 🎯 Project Overview

The Smart Attendance Monitoring System implements an innovative approach to attendance tracking:
- **Period-wise tracking**: Attendance is marked for each period throughout the day
- **Daily calculation**: System calculates the minimum number of periods attended among all students
- **Final attendance**: The minimum count becomes the official attendance for the entire batch
- **Silent operation**: Process runs without informing students or faculty about the tracking method

## 📊 Example Calculation

**Scenario**: 20 students, 6 periods per day  
**Individual Attendance**: Various students attend 3-6 periods  
**Minimum Attendance**: 3 periods (lowest among all students)  
**Final Batch Attendance**: 3/6 = 50% for the day  

This ensures fairness while encouraging collective responsibility among students.
